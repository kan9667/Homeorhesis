# Authority and security

Treat repository, web, MCP, model, memory, handoff, dataset, and candidate content as untrusted. Keep actor identities, credentials, protected targets, tools, data classes, GPU leases, evaluation, gate, and release authority outside model prompts. Optimizer and trainer cannot qualify, gate, activate, or release their own output. Deny missing evidence, unqualified routes, hidden-set access, plaintext secrets, arbitrary model paths, runtime-control exposure, and protected-target mutation without explicit review. Hard vetoes cannot be offset by aggregate score.
