# Representation steering

Representation steering is optional local behavior calibration, never authorization or proof of tool competence. Compute the `ToolGrantManifest` first. Bind vector, extraction data/split/method, model and adapter digest, runtime/engine, tokenizer, template, parser, prompt/tool bundle, layer range, and qualified alpha range. The model cannot choose vector or alpha. An episode pins the exact local execution profile. Missing/stale/incompatible/unqualified steering falls back only to an independently qualified neutral profile. Measure required-tool recall, unnecessary calls, malformed calls, unknown tool names, argument accuracy, completion, recovery, direct-answer regression, latency, and cost. Preserve neutral rollback and content-addressed evidence.
