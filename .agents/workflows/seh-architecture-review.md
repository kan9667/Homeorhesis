# SEH architecture review

1. Identify proposed decision and classify it as invariant, V1 contract, proposed, illustrative, or deferred.
2. Resolve DSH-versus-SEH ownership and avoid duplication.
3. Map actors, permissions, protected targets, evidence ownership, failure posture, migration, rollback, and operator experience.
4. Test provider/model replaceability, one-GPU behavior, task-first selection, and deterministic alternatives.
5. Require ADR/migration analysis for invariant or V1 contract changes.
6. Return accepted direction, required revisions, or rejected rationale with evidence.
