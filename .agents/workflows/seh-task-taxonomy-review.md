# SEH task taxonomy review

1. Start from observed workload and immutable objective, not a preferred model.
2. Define semantic scope, modalities, code/artifact scope, action mode, tools, context, latency, risk, locality, verifier, metrics, completion, and escalation.
3. Identify deterministic operations first.
4. Check overlap with existing families and require evidence that a split improves routing or evaluation.
5. Add schema/examples/tests and record classifier uncertainty/override behavior.
6. Do not grant route, tool, export, or production authority through taxonomy alone.
