# Authority review

Build an actor-action-resource matrix. Test denied paths, not only intended control flow.

Check GCA, qualification, scheduler/runtime manager, remote guard, evidence writers, optimizer, candidate, evaluator, trainer, memory reviewer, gate, and release manager. Verify credentials are distinct, model tools omit control operations, hidden data is evaluator-only, hard vetoes are non-compensable, and failures stop safely.
