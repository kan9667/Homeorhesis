# Model intake

Record exact source/revision/license/intended use; hash originals; scan packaging; record conversion/quantization tools and outputs; isolate artifacts; create draft runtime profile; probe load/template/parser safely; mark unqualified. Reject unclear rights, provenance, unexpected files, unsafe endpoints, or unsupported formats.
