# Local model portfolio

1. Start from task families and missing roles, not model popularity.
2. Intake exact artifacts and licenses.
3. Create exact runtime profiles and benchmark on the reference hardware.
4. Compare specialists against the current general route and deterministic baseline, including switching overhead.
5. Keep only entries with distinct measured utility; reject redundant specialists.
6. Produce a portfolio proposal with qualifications, restrictions, storage cost, and unsupported-role handling. Do not activate it.
