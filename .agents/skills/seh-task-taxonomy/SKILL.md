# Task taxonomy

Use observed task evidence. Specify semantic scope, inputs/outputs, action/code scope, modalities, context, tools, verifier, latency, risk, locality, metrics, completion, and escalation. Extract deterministic work before generative work. Keep decomposition bounded and evidence-linked. Taxonomy cannot grant route, tool, export, or release authority.
