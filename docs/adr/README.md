# SEH Architecture Decision Records

Architecture v3.1 lists ADR-SEH-001 through ADR-SEH-022. These files are proposal stubs, not accepted decisions.

Before implementation in an owning phase, replace the stub with concrete context, decision, alternatives, authority impact, evidence model, compatibility/migration, security, rollback, verification, and approval. Status must be explicit: Proposed, Accepted, Superseded, Rejected, or Deprecated.

ADR-SEH-021 governs representation steering. ADR-SEH-022 governs implementation-neutral supervised-training backends and the Unsloth provider candidate. Neither stub authorizes runtime use.
