# Phase 0-M/S checklist

- [ ] Exact neutral runtime profile recorded.
- [ ] Tool-required and direct-answer extraction corpus rights/data classes recorded.
- [ ] Extraction, development, qualification, and held-out tool-schema splits are separate.
- [ ] Difference-of-means or reviewed method reproducible.
- [ ] Vector, layers, runtime, tokenizer, template, parser, prompt/tool bundles hashed.
- [ ] Tool grant fixed before steering.
- [ ] Neutral and prompt/config baselines complete.
- [ ] Bounded alpha sweep complete.
- [ ] Required/unnecessary/malformed/unknown/argument/task/recovery/non-tool/cost metrics complete.
- [ ] Out-of-range and incompatible alpha denied.
- [ ] Model and optimizer cannot select/widen alpha.
- [ ] Episode pinning and replay proven.
- [ ] Neutral rollback proven.
- [ ] Disposition recorded; production state unchanged.
