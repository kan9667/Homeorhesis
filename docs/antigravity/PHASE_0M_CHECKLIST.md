# Phase 0-M local portfolio research checklist

- [ ] Task family and missing role defined before candidate model.
- [ ] Exact source/revision/license/intended use recorded.
- [ ] Original and converted/quantized artifacts hashed.
- [ ] Runtime engine/version/config/template/parser/tokenizer/context pinned.
- [ ] Reference hardware/driver/power/thermal state recorded.
- [ ] Separate qualification split and verifier bundle.
- [ ] Only one model resident.
- [ ] VRAM/RAM, safe context, load/unload, residual VRAM, latency, throughput, stability measured.
- [ ] Structured output, tool use, verifier success, safety, cancellation tested as role requires.
- [ ] Switch overhead compared with resident general model and deterministic baseline.
- [ ] Research disposition recorded; production remains disabled.
- [ ] Unsupported roles map to deterministic, remote, or human handling.
